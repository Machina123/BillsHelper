# Design — Infrastructure

## Docker

Single container — multi-stage build compiles the React frontend, then FastAPI serves the static assets alongside the API.

### Dockerfile stages

1. **`frontend-build` (node:20-alpine)** — copies `utilities/plewibnra/plewibnra.json` into `public/`, runs `npm ci && npm run build`, produces `frontend/dist/`
2. **`python:3.12-slim`** — installs Python deps, copies `backend/` and `frontend/dist/`, runs `alembic upgrade head` then starts uvicorn

### Static file serving

`main.py` resolves the frontend dist at:
```python
os.path.join(os.path.dirname(__file__), "..", "frontend", "dist")
```
One `..` from `app/main.py` → `/app/frontend/dist`. Two levels would overshoot to the container root.

### `docker-compose.yml`

```yaml
services:
  app:
    build: .
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data   # SQLite file persisted on host
    env_file: .env
    restart: unless-stopped
```

### Environment variables

| Variable | Default (Docker) | Notes |
|---|---|---|
| `DATABASE_URL` | `sqlite:////app/data/billshelper.db` | Four slashes = absolute path |

For local dev without Docker the default in code is `sqlite:///./data/billshelper.db` (relative path).

## Database migrations

Schema changes are managed with **Alembic**. Migration files live in `backend/alembic/versions/` and are applied automatically on container start.

| Task | Command (run from `backend/`) |
|---|---|
| Apply all pending migrations | `alembic upgrade head` |
| Roll back one revision | `alembic downgrade -1` |
| Generate migration from model changes | `alembic revision --autogenerate -m "description"` |
| Show current revision | `alembic current` |

Always review autogenerated files before committing — Alembic may miss some changes on SQLite.

## Running

### Docker (production)
```bash
cp .env.example .env
docker compose up -d --build
# App at http://localhost:8080
```

### Local dev
```bash
# Backend (Python 3.12+)
cd backend && alembic upgrade head && uvicorn app.main:app --reload --port 8080

# Frontend (Node 20 via nvm)
cd frontend && nvm use && npm install && npm run dev
# Frontend at http://localhost:5173, proxies /api → :8080
```

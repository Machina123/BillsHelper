# Design — Frontend

## Routes

| Path | Component | Purpose |
|---|---|---|
| `/` | `CreateBatch.tsx` | Select recipients, enter amounts, download transfer file |
| `/recipients` | `Recipients.tsx` | CRUD for recipients + import from bank file |
| `/settings` | `Settings.tsx` | Configure own account NRB |

## Pages

### `/` — Create Transfers
- Batch label input (pre-filled with current month/year)
- Checkbox list of all recipients; checking one expands inline fields:
  - Amount (PLN), invoice number, transfer title, execution date (optional)
- Warns if own NRB is not configured (links to Settings)
- "Generate transfer file" button: POST /api/batches → GET /api/export/{id} → browser download

### `/recipients` — Recipients
- List of saved recipients with edit and delete per row
- Sort controls inline next to the page title: **Full name** and **Short name**; clicking the active field toggles direction (↑/↓); recipients without a short name sort to the end when sorting by short name
- Inline add / edit form with full field validation
- "Import from file" button: uploads a bank recipients export `.txt`, shows added/skipped/error counts

### `/settings` — Settings
- Own bank account NRB input with live IBAN checksum validation

## Localisation

- Library: `i18next` + `react-i18next`
- Locales: English (`en.ts`) and Polish (`pl.ts`), bundled at build time
- Language persisted in `localStorage`; toggled by a button in the nav bar showing the inactive language code
- All user-visible strings are in the locale files — no hardcoded UI text in components

## Bank name lookup (`hooks/useBankRegistry.ts`)

- Fetches `GET /plewibnra.json` (static asset, served from `frontend/public/`) once on first use
- Cached permanently for the session via React Query (`staleTime: Infinity`)
- Returns a `getBankName(nrb: string): string | undefined` function
- Lookup algorithm: tries 5-digit routing prefix → 4-digit → 3-digit (longest match wins)
- NRB layout: digits 2–9 are the routing number; the prefix identifies the bank
- Bank name is shown inline after the formatted NRB on: Recipients list, CreateBatch recipient rows, Settings own-NRB field (when valid)
- The registry file is generated by `utilities/plewibnra/parse_plewibnra.py` and copied to `frontend/public/` by `make bank-registry` (called from `make install`) and by the Dockerfile frontend build stage

## Shared utilities (`utils.ts`)

- `validateNrb(digits: string): boolean` — IBAN mod-97 checksum via `BigInt`
- `formatNrb(raw: string): string` — formats 26 raw digits with spaces for display
